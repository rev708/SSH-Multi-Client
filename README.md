# SSH 탭 클라이언트 (WinForms)

PuTTY 대신 쓰는 간단한 SSH 클라이언트입니다. 탭으로 여러 서버(콘솔 1, 2, 3...)에
동시 접속할 수 있고, 서버 정보는 프로그램 안에 저장해두고 다음에 바로 골라 접속할 수 있습니다.

## 요구 사항

- Windows 10/11
- .NET 8 SDK (https://dotnet.microsoft.com/download) 또는 Visual Studio 2022 (17.8+)

## 빌드 & 실행

### Visual Studio에서
1. `SshTabClient` 폴더를 통째로 열거나, `SshTabClient.csproj`를 더블클릭해서 엽니다.
2. NuGet 패키지 복원이 자동으로 될 겁니다 (SSH.NET). 안 되면 솔루션 탐색기에서
   프로젝트 우클릭 → "NuGet 패키지 관리"에서 `SSH.NET` 설치.
3. F5로 실행.

### 커맨드라인에서
```
cd SshTabClient
dotnet restore
dotnet build
dotnet run
```

## 사용법

1. 프로그램을 실행하면 "콘솔 1" 탭이 자동으로 열립니다.
2. "서버 관리" 버튼으로 서버를 먼저 등록하세요 (이름, 호스트, 포트, 계정,
   비밀번호 또는 SSH 키 파일).
3. 콘솔 탭에서 등록한 서버를 골라 "연결"을 누르면 그 탭이 터미널이 됩니다.
4. 상단 툴바 "새 콘솔"로 탭을 계속 추가해서 여러 서버에 동시 접속할 수 있습니다.
5. 탭을 우클릭하면 "닫기"로 연결을 끊고 탭을 닫을 수 있습니다.

## 알아두면 좋은 점

- 서버 목록은 `%AppData%\SshTabClient\servers.json`에 저장됩니다.
  비밀번호/키 암호는 평문이 아니라 Windows DPAPI로 암호화되어 저장되므로,
  **이 파일을 다른 PC나 다른 Windows 계정으로 옮기면 복호화되지 않습니다**
  (그 경우 서버 관리에서 비밀번호를 다시 입력해주면 됩니다).
- 터미널은 완전한 xterm 호환 에뮬레이터가 아니라 자체 구현한 간이 VT100
  파서입니다. 일반적인 셸 사용, vim/nano 편집 등은 되지만, 아주 화려한
  TUI 프로그램(예: tmux의 일부 기능, 256색/트루컬러를 적극 활용하는 프로그램)은
  다르게 보이거나 깨질 수 있습니다.
- 이 프로젝트는 네트워크가 없는 환경에서 작성되어 실제 컴파일 테스트를
  거치지 못했습니다. 빌드 중 에러가 나면 에러 메시지를 그대로 알려주세요.
